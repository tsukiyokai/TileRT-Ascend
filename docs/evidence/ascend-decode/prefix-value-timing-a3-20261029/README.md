# Prefix Value缓存三臂计时

真实A3 9382、物理die13，固定rank2的实际M1/8193输入及2048个选择位置，计时包含完整attention与UV投影，输出边界为`[1,1024]`。三臂独立进程与私有缓存目录，12组预热、60组三臂样本、六种次序各10组；每臂计时前读写256MiB压力并同步，计时关闭profiler，保留全部样本。[原始报告](report.json.gz)与[独立读回](readback.json)核对180个输出、双时钟统计、输入/缓存未变及六种次序。

| 实现 | 墙钟p50/µs | 墙钟p95/µs | event p50/µs | event p95/µs |
| -- | -- | -- | -- | -- |
| 原生SFA＋UV | 263.544 | 304.191 | 197.310 | 240.140 |
| 完整展开 | 783.941 | 1199.291 | 738.320 | 1090.600 |
| 缓存prefix Value | 906.016 | 1150.459 | 808.510 | 1020.060 |

预注册要求缓存墙钟p50至多为展开的0.8倍，实际为1.156倍，预测失败；相对原生为3.438倍，60组中0组更快，相对展开14组更快。原生逐位复现既有真实SFA捕获，展开逐位复现既有组合设备输出，缓存逐位匹配固定CPU PV；三者输出不要求彼此逐位相等。原生参考捕获与夹具按各自页表重建8193行有效KV核对，无效padding不参与跨捕获比较。

此实现结束性能接入，保留数值干预和缓存接线证据。源码移走prefix投影，但仍收集完整KV并执行dense PV；减少重算未降低本次墙钟。慢因尚未做分项归因，不追加舍入或布局旋钮。已有resident采集还包含诊断head及状态搬回，其耗时不能充当生产verify时延。

[冻结收据](receipts.tar.gz)含实际脚本、预注册契约、命令、私有缓存设置、加载库SHA及前后设备状态。未锁频；温度/功耗快照与不受支持的频率查询原文均保留。前后8组NPU进程表为空，前后采样均为原三个既有容器；本方容器退出0后退役。本次没有完整模型精度、连续32步、width32或在线TPOT通过。原报告的`native_performance_adoption_met`只指预注册双钟p50条件；独立读回另核对p95，二者均失败。
