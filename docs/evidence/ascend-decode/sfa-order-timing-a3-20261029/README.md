# SFA索引排序三臂计时

真实A3 9382、物理die12，使用[三臂TP16捕获](../layer68-boundaries-a3-20261029/README.md)的rank12实际M1和完整M32 SFA输入。每个width三臂使用独立进程与私有缓存，12组预热、60组计时，六种次序各10组；每次计时前读写256MiB并同步。profiler与graph关闭，未锁频；前后设备及温度/功耗快照随收据保留。计时边界为一次完整SFA；预排序在准备阶段完成，每次排序臂包含FP32 cast、排序及整数cast，均不含UV、TP或其他层。

预注册要求预排序双钟p50/p95均至多为原生0.95倍，两种width均失败；每次排序含完整额外成本，亦失败。M1预排序event略降，墙钟仍增，不能据此宣告净收益。此排序实现停止性能接入，保留[数值因果结果](../sfa-order-a3-20261029/README.md)。不再追加相近排序旋钮，也不把同一夹具重复调用解释为跨四层摊销收益。
