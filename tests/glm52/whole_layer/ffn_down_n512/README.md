# Down N512 tiling

This candidate starts from the validated `381febf94f918cc7393019b6f99ec8dc38e9a5cc9e63b2d49d5fe483158e3ff2` FFN. Only Down's host tiler adds `SetFixSplit(-1,512,-1)`. The returned ND and NZ tilings must both be M64/N512/K128, with the recorded loop depths, buffer counts and resource sizes; an unexpected tiling fails preparation. The device source, GU static configuration, original shared quantization, per-expert ownership, all five body joins and terminal publication remain unchanged apart from independent public symbols.

For every expert count `1 <= c <= 32`, `SetSingleShape(2*c,6144,128)` still has one M tile and one K tile. Twelve N512 tiles replace twenty-four N256 tiles. The result retains row stride 6144 and the same compact high/low row addresses. N512 spans eight complete INT4 NZ N64 blocks, so it needs no repacking or tensor view. Each K128 INT32 dot has magnitude at most `128*64=8192`; the FP16 MSD and later BF16 boundaries are unchanged.

The [installed CANN 9.2 host-tiling audit](../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/ffn-down-geometry-source-audit/README.md) records L0A 8192 bytes, double-buffered L0B 65536 bytes, single-buffered L0C 131072 bytes and L1 397312 bytes. L0B and L0C exactly reach the A3 platform limits. Down has the AIC after its existing `pipe.Reset()`; the concurrent shared-store phase uses AIV UB. No other live AIC allocation shares these L0 buffers. The full B matrix already fits L1 in the parent, so this change does not imply lower HBM traffic.

The namespace is `tilert_ffn_down_n512`; the C ABI is `ffn_down_n512_launch`. The 33 scratch tensors, 408-byte descriptor and 112-byte shared-input structure retain the parent ABI. Routed-body UB remains 116480 bytes; the earlier norm phase allocates 195584 bytes and resets before the body. The complete-FFN peak is therefore 195584 bytes. The original Decoder norm/MLP remains the numerical oracle. The inherited `parent-check.py` uses historical shared arithmetic and is not an acceptance test. First require raw-byte equality of GU/Down integer results and all production outputs across counts, layouts and changing graph replays; then compare full FFN event time with 381feb using both common-address arenas and at least 30 independent samples per arm.

The frozen `build-v2` library is `c90b3666a1697070eda19d5b3e133e9ed58f36fe429abefceae6ffe102a6a032`. The [original Decoder FFN gate](../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/vendor-hook-decoder212-ffn-down-n512-wide-v1-a3-194/summary.json) passed all 64 cases: two layers, M1/2/12/32 and eight changing inputs. All 704 raw-byte comparisons passed, including 256 immediate consumers. Eight preparations and 64 replays also matched the complete 200-byte N512 tiling (`bb8ef4481b8c63b00dc43940975ee5b172818bcd228e8bc553b22234cbb2a244`). Four original NZ allocations and their bytes were preserved. This gate uses synthetic parameters, one physical die and local pre-AR2 outputs; TP collectives were not executed.

The [paired benchmark](bench/prepare_bench.py) compares N512 directly with its 381feb N256 parent at M12/24 groups, 16 weight banks and 30 alternating event samples per arm in each of two owner arenas. Thirty-two scratch addresses are shared. Only `body[7]` differs: each arm retains its own prepared Down-tiling tensor and owner, checked against the [full host-tiler byte oracle](expected-tilings.json) before and after capture and timing. Eight x86 and eight ARM CPU contracts passed, including actual frozen C ABI headers, owner preservation and rejection of an erased or partially changed tiling. All five actual libraries loaded without initializing the NPU.

The [paired device result](../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/ffn-down-n512-timing-v1-a3-194/summary.json) passed 19,200 raw-byte boundary checks, 360 event-tail checks, 696 complete active-table checks and 20 full-tiling checks. At E65, candidate/parent median times were 201.130/211.521 µs and 200.005/209.023 µs in the two owner arenas; median paired savings were 10.418 and 8.867 µs, with all 60 pairs faster. These are complete local FFN event times under identical corrected shared arithmetic. They do not measure TP collectives, model TPOT or the sum of gains from earlier experiments.
