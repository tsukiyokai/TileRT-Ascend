# K128 versus K64 at fixed FFN addresses

This benchmark retains the measured N1024 protocol. The candidate is K128 `0842cd0f`; the control is N1024/K64 `bbd52e42`. Both arms keep all weights and 32 scratch addresses identical. The prepared body slot 7 remains private to each original Tensor owner: complete 200B records `c2b73af9` and `c207230a` are checked before/after capture and timing. No per-replay tiling upload is added.

Two owner arenas each use M12, 24 groups, 65 active experts, 16 distinct weight banks, 16 calls per graph and 30 graph replays per event. Thirty alternating pairs form 15 ABBA cycles per arena. Owning-Torch comparisons, fresh-write poisoning, all 264 active-table words, event windows and output snapshots remain unchanged. The expected totals are 19200 raw numerical checks, 360 event-tail checks, 696 active-table checks and 20 complete-tiling checks. This experiment tests the K-loop versus lost L0A/B ping-pong tradeoff; it does not measure whole-model TPOT.

The original Decoder random and hot-expert numerical gates precede device timing. This directory builds and checks only the frozen harness and CPU ABI; root owns all device execution.

The [frozen timing evidence](../../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/ffn-down-k128-timing-build-v1/handoff.json) records eight passing x86 contracts, eight passing actual ARM contracts and successful co-loading of all five pinned Torch 2.12 DSOs with NPU uninitialized. Both C ABI declarations are compiled from their own frozen headers. The benchmark SHA is `b85e7d69bca2ae1636617ae44fe06d27f3aa1f5134cd8eaffaebc08b396589fe`; manifest SHA is `2c159253196069a8ffc7a28e3f030e2c12d719ec8807b030306afe2efad4d6ab`. All 16 frozen files and five libraries are verified on a3-194.

The [device result](../../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/ffn-down-k128-timing-v1-a3-194/summary.json) passes every numerical, event-tail, active-table and complete-tiling check listed above. Across the two owners, candidate/control medians are 203.950/211.309 and 203.187/209.089 us; paired median savings are 7.339/5.872 us, with 60/60 wins. Report SHA is `d7e86d46a80dc0df5cd973ce4032472922f336cb7bb4b2bbc8b0b90ae370e0f4`. The conclusion is local to M12/24/E65 and this working set.
