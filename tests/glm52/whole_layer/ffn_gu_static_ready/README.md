This composition applies the validated expert-ready schedule to static-GU FFN library `381febf94f918cc7393019b6f99ec8dc38e9a5cc9e63b2d49d5fe483158e3ff2`. Each AIC publishes a complete expert GU product to its two AIVs with mode2 ready flag 8. Both consumers acknowledge through flag 9; at most four publications remain outstanding, and all credits drain before the original second body join. Expert counts below the AIC-group count retain the globally balanced activation path.

The static GU tiling, five body joins, shared key30013 arithmetic, terminal completion, 33 public tensors, 408-byte descriptor and routed-body UB allocation of 116480 bytes are retained. The preceding norm uses 195584 bytes and resets its arena before the routed body. Mathematical helpers and the Down/output phases are unchanged. No extra GM or UB storage is allocated.

Library `affc88ba` passes the [original DecoderLayer norm/MLP comparison](../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/vendor-hook-decoder212-ffn-gu-static-ready-wide-v1-a3-194/summary.json) at M1/2/12/32 with both weight sets: 448 arithmetic boundaries and 256 poisoned immediate graph consumers match byte for byte. The inherited checker retains historical shared arithmetic and is not this composition's acceptance oracle.

The [paired timing comparison](../../../../docs/evidence/ascend-decode/megakernel-device-20261021/integration/ffn-gu-static-ready-timing-v1-a3-194/summary.json) rejects this composition for performance. Median paired regressions are 6.006/2.449 us; none of the 60 pairs favors the candidate. All 19,200 raw-byte, 360 event-tail and 696 active-table checks pass. All 33 scratch addresses are shared within each pair. Static-GU parent `381febf9` remains selected. The separate static-GU and expert-ready gains do not combine in this schedule; the cause of the regression has not been isolated.
